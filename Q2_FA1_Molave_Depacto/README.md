# Short Reflection

1. **What functions did you create in your calculator program?**

   I created four functions: `add_numbers`, `subtract_numbers`, `multiply_numbers`, and `divide_numbers`.

2. **What parameters did your functions use?**

   Each function used `num1` and `num2` to receive the two numbers.

3. **What arguments were passed when the functions were called?**

   The two numbers entered by the user were passed to the selected function as arguments.

4. **How did your program use the returned value?**

   The program stored the returned result in a variable and displayed it to the user.

5. **Why is it better to divide the calculator program into functions instead of writing everything in one long block of code?**

   Functions make the code easier to read, organize, test, and fix.
